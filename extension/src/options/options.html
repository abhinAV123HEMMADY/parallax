Parallax — Watch & Note

Notes you capture on YouTube sync to Parallax. No sign-in, no setup.

Where “Open export” sends you. Deployed, this is a different domain than the backend.

There is no authentication. Anyone with this extension and your backend URL can read and write notes for the built-in learner. The production answer is a token issued by a sign-in page in the Parallax web app and stored per install; that does not exist yet, so run this against a local or private backend only.
